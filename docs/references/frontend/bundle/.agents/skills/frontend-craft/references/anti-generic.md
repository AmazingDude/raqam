# Avoiding the generated-page look

These are defaults, not choices. Use one only if the brief asks for it.

- Warm cream background with a high-contrast serif and a terracotta accent.
- Near-black background with a single acid-green or vermilion accent.
- Newspaper-style hairline rules with zero border radius everywhere.
- Content chopped into identical rounded cards with the same soft shadow and gradient washes.
- Tracked-out ALL-CAPS eyebrow labels above every heading; meta strings joined with middle dots; "WORD — fragment" labels; arrows appended to every link.
- One accented word in each headline; numbered 01/02/03 markers on content that is not a sequence.
- Fade-and-slide-up on every section and hover lift on every card.

## Instead

- Take vocabulary, materials, and colors from the subject's own world.
- Use one type family or two clearly distinct ones; size and weight carry hierarchy.
- Vary radius and elevation by hierarchy, not one value for everything.
- Open with the most characteristic thing in the subject's world: a live demo, a real image, a striking headline.
- Structure (borders, labels, numbering) must encode real information.

## Copy checklist

- Name things as the user would, not as the system is built.
- One job per written element.
- Empty states invite an action; errors explain the fix and never apologize.
