# Prompting guide

Formula: **subject + setting + light + camera/medium + mood + constraints**.

- Be concrete: "a weathered brass compass on dark slate" beats "a nice compass".
- Name the light: "overcast soft light", "low golden hour side light", "neon rim light".
- Name the framing: "close-up", "top-down", "wide establishing shot".
- State constraints last: "no text, no watermark, empty space on the left for copy".
- For hero banners, ask for negative space on the side where the headline will sit.
- For consistency across a set, reuse the same palette and lighting sentence verbatim and pass a `--ref`.
- If hands, text, or small details fail, simplify the scene or crop in CSS.
- Change one variable per iteration so you learn what caused the difference.
